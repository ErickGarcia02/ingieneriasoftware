Cast | Pronóstico de demanda
Inicio rápido en Streamlit Community Cloud

1. Descomprime Cast.zip. En tu repositorio existente actualiza app.py, motor.py y requirements.txt juntos. Mantén ejemplo_tickets.csv junto a app.py y .streamlit/config.toml en la raíz del repositorio.
2. Guarda los cambios en la rama conectada a Streamlit Cloud. El archivo principal es app.py. Cast arranca con un ejemplo de tickets en Operaciones.
3. Selecciona un departamento y abre Fuentes y conjuntos de datos. Sube un CSV o XLSX, elige la hoja si corresponde, indica las columnas de fecha y volumen y pulsa Importar conjunto. Para archivos con un ticket por fila usa Contar una unidad por fila.
4. Abre Pipeline y calidad para consultar rechazos y descargar datos. En Modelos y pronósticos selecciona un horizonte de 7, 14, 30, 90 o 120 días y pulsa Generar pronóstico. El dashboard permite alternar entre vista diaria y semanal. Las vistas semanales resumen el pronóstico diario dentro del horizonte solicitado.
5. Para evaluar un pronóstico guardado, importa el historial actualizado (completo, incluidas las fechas nuevas) con el mismo nombre y reglas. En Historial elige la ejecución anterior y revisa Real, Pronóstico, MAE y WAPE para las fechas coincidentes.

Usa fechas AAAA-MM-DD. Ejemplo: Fecha,Tickets. Reúne al menos 14 días de historial con 10 días observados. Los conjuntos, modelos e historial de cada departamento viven en la sesión del navegador. Al recargar o cerrar la sesión puedes perderlos. Descarga los CSV que quieras conservar.

Windows: extrae el ZIP antes de abrir Iniciar_Cast.bat. Usa Python 3.11–3.14 con acceso a Internet para instalar dependencias. Mantén la ventana abierta mientras usas Cast.
Inicio manual desde la carpeta: python -m pip install -r requirements.txt
Después ejecuta: python -m streamlit run app.py
